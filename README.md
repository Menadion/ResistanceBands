# Resistance Bands

An Obsidian graph view where chosen folders get their own link length.

Obsidian's graph has a single Link distance slider that moves every line at once, which is only a
zoom. This plugin lets you pick folders and give the links touching them a longer or shorter
resting length than the rest, the way a resistance band set comes in different lengths.

**In development.** Nothing is drawn yet, and there is no release. This README will be filled in
once the view renders.

## Status

- Reads the vault's links and honours the app's own Excluded files setting
- Every link is assigned a length from the graph's Link distance and the rules that match its ends
- Next: hand those lengths to the force simulation and paint the graph
